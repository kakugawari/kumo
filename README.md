# くもスケッチ

空に雲を描く、静かなスケッチ帳。単一 HTML の PWA。

## 中身

```
index.html            アプリ本体(HTML/CSS/JS すべて内包)
manifest.webmanifest  PWA マニフェスト
sw.js                 Service Worker(オフライン対応・キャッシュ先読み)
                アイコン一式(192 / 512 / maskable / apple-touch / favicon)
```

## GitHub Pages に置く

1. リポジトリを作り、フォルダの中身をそのままルートに置く(index.html / manifest.webmanifest / sw.js / png 5点)
2. Settings → Pages → Branch: `main` / `(root)` で公開
3. iPhone は Safari で開き、共有 → 「ホーム画面に追加」

サブディレクトリ配信でも動くよう、パスはすべて相対にしてあります。

## 更新のしかた

`index.html` を書き換えたら **`sw.js` の `CACHE` を `kumo-sketch-v2` のように上げる**こと。
上げないと端末側の古いキャッシュが残り、更新が反映されません。

## 描き方

- ブラシは高さ順に3段。高い空(筋雲・鱗雲・霞雲・飛行機雲)/ 低い空(綿雲・入道雲・畝雲)/ 他の道具(光・太陽・消しゴム)
- 「太陽」を選んで空をなぞると太陽が動き、すべての雲の陰影が付け直される
- 飛行機雲は指を動かした方向に伸びる
- 左上のロゴをタップ → 空(色・太陽・風)/ 音 / 元に戻す / リセット / 保存

## 技術メモ

雲は粒ごとに陰影をつけていない。加算合成で濃度場を作り、フラクタルノイズで揺らしたうえで、
各ピクセルから太陽方向へ 4〜9 歩レイマーチして光の減衰 `T = exp(-Σ密度)` を求め、
その透過率だけで色を決めている(薄い縁ほど明るく金色に抜ける)。
雲レイヤーは画面幅でループし、端をまたぐ雲は 1 画面分ずらした位置にも描いて継ぎ目を消している。
